# SnapCanvas

SnapCanvas is a modern, responsive web application designed for exploring and searching high-resolution photography. 

### Design Decisions
1. **Emerald & Slate Dark Theme**: Chosen to offer a clean, high-contrast visual experience optimized for modern media viewing, clearly departing from standard reference layouts.
2. **Quick-Pick Suggestion Chips**: Implemented an intuitive category filter row allowing users to instantly target popular visual themes with a single click.
3. **Responsive CSS Grid**: Built using `grid-template-columns` with `auto-fill` and `minmax` to guarantee fluid adaptation across all screen sizes from mobile viewports to ultra-wide displays.
